Quantifying the Hidden Costs of Open-Source License Selection

B. E. Akbaba, B. Kutlu, M. K. Oğuzer, S. Nazlıoğlu

2026 5th International Informatics and Software Engineering Conference (IISEC), Ankara · DOI: 10.1109/IISEC69317.2026.11418416

Açık kaynak lisans türünün (permissive, zayıf copyleft, güçlü copyleft) proje bakımına etkisini ampirik olarak inceledik. Altı farklı lisansa sahip 60 GitHub deposunun 120 günlük aktivitesini GitHub REST API ile topladık. Permissive lisanslı projeler daha fazla katkıcı çekiyor ama bakımcıya daha fazla yönetim yükü getiriyor; copyleft projeler ise daha az katılım alsa da daha istikrarlı ve kontrol edilebilir kalıyor. Issue çözüm süresi lisanstan değil, projenin iç yönetiminden etkileniyor. Bu yüzden lisans seçimi yalnızca hukuki değil, stratejik bir operasyonel karar.

We empirically examined how license type (permissive, weak copyleft, strong copyleft) affects open-source maintenance, using 120 days of activity from 60 GitHub repositories across six licenses, collected via the GitHub REST API. Permissive projects attract more contributors but place a heavier administrative load on maintainers, while copyleft projects see less participation but stay more stable and manageable. Issue resolution time depends on internal project management rather than the license, so choosing a license is a strategic operational decision, not only a legal one.

Yüksek lisans tezi · Atılım Üniversitesi · 2026MSc thesis · Atılım University · 2026

A Document-Based LLM-Driven Adaptive Learning System

Kural tabanlı uyarlanabilir öğrenme sistemlerinin esneklik sorununa karşı, büyük dil modelleriyle çalışan bir uyarlanabilir öğrenme çerçevesi geliştirdim. Sistem, öğrencinin etkileşimlerine göre açıklamalar üretiyor, soru zorluğunu ayarlıyor ve anlık geri bildirim veriyor. Back-end Python, arayüz JavaScript/React ile yazıldı; içerik üretimi için Ollama üzerinde çalışan, doküman tabanlı Llama 3.1 modeli kullanıldı. Etkileşim ve performans odaklı deneyler, LLM tabanlı uyarlamanın özellikle anlık geri bildirim ve zorluk ayarlamada sistemin tepki verme ve uyum yeteneğini artırdığını gösterdi.

To overcome the rigidity of rule-based adaptive learning systems, I built an LLM-driven adaptive learning framework that generates explanations, adjusts question difficulty and delivers real-time feedback based on each learner's interactions. The back end is written in Python and the interface in JavaScript/React, with a document-based Llama 3.1 model served through Ollama for content generation. Experiments on engagement and performance showed that LLM-driven adaptation improves the system's responsiveness and adaptability, especially in real-time feedback and difficulty adjustment.
